# سوالف v47 — إصلاح خطأ checked عند تسجيل الدخول

## المشكلة
عند تسجيل الدخول إلى حساب سوالف قد يظهر: `Cannot set properties of null (setting 'checked')`.
هذه رسالة JavaScript وليست دليلاً على خطأ كلمة المرور أو مفتاح OpenRouter.

## ما الذي تغير؟
- أصبحت استعادة مسودة المحادثة وتحميل إعدادات الذاكرة والإشعارات تتحقق من وجود عناصر الاختيار قبل تعديل حالتها.
- أصبح تفويض محرك Claude Code يستعمل نفس عنصر الخيار الذي تحقق من وجوده سابقاً، حتى لا يحدث خطأ عند تغيّر الواجهة أثناء الطلب.
- جرى تعديل حقل السوق الاختياري أيضًا حتى لا يوقف الواجهة عند غيابه.
- جرى تحديث إصدار ملفات الواجهة والكاش إلى v47 لتقليل مزج الإصدارات القديمة والجديدة.

## التركيب على نسخة المصدر v46
1. أغلق سوالف، وخذ نسخة احتياطية من مجلد المشروع.
2. فك ضغط الحزمة، وانسخ `index.html` و`sw.js` والملفات الموجودة داخل `js/` فوق الملفات المناظرة في مجلد سوالف الأصلي.
3. لا تمسح `localStorage` أو `IndexedDB` أو بيانات الموقع: فيها محادثاتك وإعداداتك.
4. افتح `Start-Sowalif.cmd` ثم `http://127.0.0.1:4781/`، واضغط `Ctrl + Shift + R`.
5. جرّب الدخول إلى حساب سوالف.

> لو تستخدم `Sowalif.exe` القديم، يلزم إنشاء نسخة جديدة من المصدر حتى يتحدث البرنامج.

## اختبار آلي
```powershell
node --test tests/account-checkbox.test.mjs
```

## حدود التحقق
تم اختبار الحماية من عناصر checkbox المفقودة محلياً دون استخدام حسابك أو كلمة مرورك. لا يمكن ضمان انتهاء خطأ الدخول إلا بعد تجربته على جهازك؛ إذا بقي، انسخ رسالة Console كاملة مع الملف ورقم السطر (من دون مشاركة كلمات مرور أو مفاتيح).
