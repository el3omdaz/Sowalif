# سوالف — تحديث v44 | مساحة أكبر للمحادثة وهيستوري قابل للطي

هذا تحديث **للواجهة فقط فوق v43**. يحافظ على إصلاحات المرفقات ومحرك Claude Code والتفويض التلقائي في الإصدار السابق. **لا يحتاج إعادة بناء Docker ولا إدخال مفتاح OpenRouter مجددًا.**

## الجديد

- شريط الهيستوري على الكمبيوتر بثلاث حالات: **كامل (226px)**، **أيقونات (62px)**، **مخفي (0px)**.
- الوضع الافتراضي عند أول استخدام: أيقونات فقط؛ ويمكن تغيير الوضع من الإعدادات ← العرض والصوت ← مساحة قائمة المحادثات على الكمبيوتر.
- زر التبديل أعلى قائمة الهيستوري للانتقال بين الكامل والأيقونات.
- زر القائمة أعلى المحادثة لإخفاء الهيستوري وإعادته بضغطة واحدة، مع حفظ اختيارك على نفس الجهاز.
- شريط الأقسام أصغر ويبقى في صف واحد عند وضعه فوق المحادثة؛ وعلى الجنب يبقى شريطًا عموديًا قابلًا للطي.
- توسيع عرض الرسائل وحقل الإدخال حتى 1120px على الشاشات الواسعة.
- الجوال: الهيستوري قائمة مؤقتة فوق المحادثة؛ لا تُحجز له مساحة دائمة.
- استعادة قواعد v41 لتصغير شريط الأقسام التي فُقدت عند استبدال CSS في v43.

## التثبيت على نسخة v43

1. أغلق سوالف بالكامل، واحفظ نسخة احتياطية من مجلد المشروع.
2. فك ضغط `Sowalif_v44_Compact_Chat_UI.zip`.
3. انسخ الملفات والمجلدات **بنفس هيكلها** إلى جذر مشروع سوالف بجانب `package.json` و`index.html`؛ وافق على **Replace files in destination**.
4. الملفات المستبدلة: `index.html` و`style.css` و`sw.js` و`js/app.js` و`js/nav-layout.js`. ملف `tests/history-layout.test.mjs` اختياري للمطور.
5. **نسخة الموقع على GitHub Pages:** ارفع التعديلات إلى مستودع الموقع، انتظر إكمال النشر، ثم اضغط `Ctrl+Shift+R` لتحديث المتصفح. لا تمسح بيانات الموقع المحلية.
6. **نسخة التشغيل من المصدر عبر `Start-Sowalif.cmd`:** أغلق الخدمة ثم شغّلها مجددًا، وافتح نسخة المتصفح المحلية وأعد تحميل الصفحة.
7. **نسخة ويندوز `Sowalif.exe`:** مجرد تعديل ملفات المشروع **لا يحدّث EXE القديم**. من جذر المشروع على Windows ومع Node.js وملفات البناء الأصلية شغّل:

```powershell
npm run desktop:build -- --zip
```

ثم افتح النسخة الجديدة من `desktop/dist`، وانقل مجلد التشغيل كاملًا. لا تعتمد على اختصار نسخة قديمة.

## الفحص

```powershell
node --test tests/history-layout.test.mjs tests/workspace-nav.test.mjs
```

يمكنك اختيار **موقع شريط الأقسام** مستقلًا عن **حجم الهيستوري**. التفضيلات تحفظ على كل جهاز في تخزين المتصفح المحلي، ولا تُرفع مفاتيح API أو المحادثات ضمن هذا التحديث.

> ملاحظة: تم اختبار تبديل واجهة العرض محليًا في متصفح Chromium باختبارات غير متصلة بمزوّد حقيقي؛ يلزم التأكد من المظهر على نسخة Windows بعد إعادة البناء.
