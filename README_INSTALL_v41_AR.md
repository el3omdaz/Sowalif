# سوالف — تحديث الواجهة v41 مع إصلاح المرفقات v40

هذا تحديث **تراكمي للكود المصدري** (يحتوي على ملفات v40 السابقة إضافة إلى تحديث الواجهة v41)، **ليس ملف EXE**.

## المزايا الجديدة

- تصغير أزرار الشات والصور والفيديو والشغل والإدارة والسوق العلوية.
- خيار تغيير موضع شريط الأقسام من فوق إلى جانب واجهة المحادثة على الكمبيوتر.
- زر **طي الشريط** يحوله إلى أيقونات لتوفير مساحة؛ والضغط عليه ثانية يوسعه.
- يتذكر سوالف موضع الشريط وكونه مطويًا على **نفس الجهاز/المتصفح**.
- عند عرض سوالف على شاشة بعرض 820px أو أقل، ينتقل التنقل تلقائيًا إلى أعلى الواجهة دون إلغاء اختيار المستخدم للكمبيوتر.
- تحسين مقاس أدوات الصور والشغل، مع الحفاظ على إصلاحات PDF وZIP في v40.

## تثبيت التحديث في المشروع

1. أغلق سوالف وخذ **نسخة احتياطية** من مجلد المشروع.
2. افتح ZIP وانتقل إلى مجلد مشروع سوالف الذي يحتوي `index.html` و`style.css`.
3. فك محتويات ZIP في **جذر المشروع** مع دمج مجلد `js` واستبدال الملفات الموجودة.
4. تأكد من وجود الملفات الجديدة/المحدّثة: `index.html` و`style.css` و`sw.js` و`js/nav-layout.js`.
5. إذا تستخدم نسخة ويب منشورة، انشر تغييرات المصدر على استضافتك (رفع الملفات محليًا وحده لا يغيّر GitHub Pages).
6. افتح/حدّث التطبيق؛ إذا بقي التصميم القديم أغلق جميع نوافذ سوالف ثم افتحه، أو استخدم تحديثًا قويًا `Ctrl+Shift+R` على الويب.

> **مهم لنسخة Windows:** إذا تعمل من `Sowalif.exe` الجاهز، تحديث المصدر لا يغير EXE القديم. لإنتاج نسخة جديدة على Windows من مجلد المشروع شغّل `npm run desktop:build -- --zip` بعد إعداد Node وإكمال متطلبات البناء. ثم افتح `Sowalif.exe` الجديد داخل `desktop/dist`. لا تستبدل ملفات البرنامج داخل توزيع EXE القديم عشوائيًا.

## مكان الخيار الجديد

**الإعدادات ← العرض والصوت ← شريط الأقسام ← مكان الشريط**، ثم اختر `فوق المحادثة` أو `على الجنب`.

على الجنب يظهر زر **طي الشريط** أسفل الأيقونات. الرجوع إلى «فوق» يحافظ على اختيار الطي لوقت لاحق.

## فحص سريع

1. انتقل بين الشات والصور والفيديو والشغل، ثم افتح الإدارة والسوق للتأكد من بقاء الأزرار تعمل.
2. بدّل الموضع من الإعدادات إلى جانب، وجرّب طي الشريط وتوسيعه.
3. أغلق التطبيق ثم افتحه من جديد للتأكد من حفظ الاختيار على الجهاز نفسه.
4. جرب تصغير النافذة إلى مقاس جوال وتأكد أن الشريط يعود للأعلى.
5. جرّب «نموذج 5-1.pdf» و«حافظة ai.zip» للتأكد من إصلاحات المرفقات السابقة؛ لا نفترض نجاحها مع كل ملف دون تجربة حقيقية.

## الاختبارات والقيود

- اختبرت موضع الشريط والتبديل والطي وإعدادات الجوال في Chromium محليًّا من واجهة ثابتة، واختبار Node مستقل لحالات التنقل.
- تشغيل الاختبارات الشاملة في بيئة الفحص أعطى **208 نجاحات، 3 مجموعات فشلت في التحميل** لعدم توفر حزمة `fake-indexeddb`، واختبارًا واحدًا متجاوزًا. لم أشغّل نسخة Windows التنفيذية على جهازك.
- التحديث لا يغير خدمات API أو مفاتيحها ولا يعيد بناء EXE تلقائيًا.
- إذا عدّلت ملفات المشروع بعد v40، راجع الفرق قبل استبدالها حتى لا تكتب فوق تعديلاتك الخاصة.
