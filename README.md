# المحادثة الذكية

تطبيق محادثة عربي يشتغل في المتصفح على الكمبيوتر والآيفون، ويستخدم نماذج [kie.ai](https://kie.ai).
ما يحتاج سيرفر: الصفحة تكلم kie.ai مباشرة بمفتاحك.

## الخصوصية
- المفتاح والمحادثات والصور تنحفظ على جهازك فقط (localStorage و IndexedDB)، وما ترفع لـ GitHub.
- الطلبات تروح مباشرة من جهازك إلى kie.ai.

## الآيفون
افتح الرابط في Safari، اضغط زر المشاركة ⬆️، واختر «إضافة إلى الشاشة الرئيسية»، وبعدها حط المفتاح في ⚙️.

## الميزات
- 11 نموذج (Claude وGPT وGemini وGrok وDeepSeek وKimi)، والتلقائي Claude Fable 5
- 🌐 بحث في الإنترنت · 🧠 تفكير أعمق · 🎨 توليد صور (Nano Banana 2.1)
- 📎 صور وPDF وWord وملفات نصية · 🎤 تحويل الصوت إلى نص
- تصدير المحادثات واستيرادها بين الأجهزة

## التطوير
الموقع ملفات ثابتة بدون بناء. لتحديث المكتبات: `npm install` ثم انسخ الملفات المطلوبة إلى `vendor/`.
