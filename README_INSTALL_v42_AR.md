# سوالف — إصلاح زر «ربط المحرك» v42

**هذا تحديث مصدر صغير يُركب فوق v41، وليس ملف EXE جاهزًا.** يحتوي فقط على الملفات التالية: `index.html` و`js/app.js` و`sw.js`.

## سبب المشكلة

في الإصدار السابق، الزر `#codingSetup` كان ينفّذ `openSettings('agent')` في كل ضغطة. لا يعني حفظ مفتاح OpenRouter تشغيل Claude Code. محركات البرمجة تحتاج خدمة سوالف المحلية، وبيئة Docker المهيأة.

## ما تغير

- في موقع GitHub Pages أو أي عنوان ويب عام: أصبح زر «ربط المحرك» بعنوان «فتح نسخة الكمبيوتر» ويفتح `http://127.0.0.1:4781/` في تبويب جديد. إذا لم تفتح، شغّل `Start-Sowalif.cmd` من مشروع سوالف.
- في نسخة الكمبيوتر المحلية: يتحول إلى «فحص اتصال المحرك»، ويتحقق من الوصول إلى الخدمة، وجاهزية Docker والمحرك، ويعرض رسالة نجاح أو سبب التعذّر.
- عند اختيار Claude Code من قسم الشغل: لا يعيد فتح الإعدادات تلقائيًا إذا كان مفتاح المحرك محفوظًا؛ لكنه يطالب بالمفتاح في حال غيابه على **النسخة المحلية**.
- أضيف رابط ثانٍ في إعدادات المحرك لنسخة `Sowalif.exe` المحلية على المنفذ `4782`.
- تحديث إصدار ملفات الواجهة إلى `v42` لتقليل ظهور نسخة قديمة من الذاكرة المؤقتة.

## التركيب

1. احفظ نسخة احتياطية من مشروع سوالف الحالي.
2. فك ZIP في **جذر مشروع سوالف** الذي يحتوي `index.html`، ووافق على استبدال **الملفات الثلاثة فقط**. لا تمسح مجلد `js`؛ ادمج الملف داخله.
3. **إذا تستخدم موقع GitHub Pages:** ارفع/انشر الملفات المعدلة على المستودع. استبدال الملفات على جهازك لا يحدث الموقع المنشور. افتح الموقع ثم `Ctrl+Shift+R`.
4. **إذا تستخدم Sowalif.exe:** أعد بناء النسخة على ويندوز باستخدام `npm run desktop:build -- --zip` ثم افتح `Sowalif.exe` الجديد داخل `desktop/dist`، وليس اختصار نسخة قديمة.
5. **إذا تستخدم Start-Sowalif.cmd:** شغل الخدمة ثم افتح `http://127.0.0.1:4781/`.

## تشغيل Claude Code — خطوة مستقلة عن تحديث الزر

1. ثبّت Docker Desktop وشغّله.
2. من مجلد مشروع سوالف نفّذ `npm run agent:setup` (مرة واحدة بعد بناء بيئة المحرك أو تحديثها).
3. شغّل `Start-Sowalif.cmd` أو افتح نسخة `Sowalif.exe` المبنية حديثًا.
4. افتح **النسخة المحلية** على `http://127.0.0.1:4781/` (من تشغيل السكربت) أو `http://127.0.0.1:4782/` (من EXE).
5. في النسخة المحلية اختر «الشغل» ← Claude Code ← ربط المحرك/فحص اتصال المحرك. اختر OpenRouter واحفظ مفتاح API **في هذه النسخة المحلية** إذا لم يكن محفوظًا. مفاتيح المتصفح على موقع GitHub Pages لا تنتقل تلقائيًا إلى عنوان محلي مختلف.
6. اختبر الاتصال حتى تظهر رسالة «جاهز» قبل تجربة البرمجة.

> مهم: هذا الإصلاح يحسن سير الواجهة وتشخيص الاتصال، لكنه **لا يسمح بتشغيل Claude Code على GitHub Pages مباشرة**، ولا يشغّل Docker تلقائيًا. لم يتم اختبار مفتاح OpenRouter حقيقي أو تشغيل Claude Code المدفوع.

## التحقق

- `node --check js/app.js` و`node --check sw.js` نجحا.
- تم تشغيل الاختبارات المحددة لتنقل الواجهة ومحرك الكمبيوتر: 9 نجاحات، اختبار واحد مؤجل، دون إخفاقات.
