# سوالف v46 — إصلاح اختفاء زر «ملفات المشروع»

## ما المشكلة؟
في v45 كانت الدالة `renderProjectCount()` تخفي زر **«ملفات المشروع»** إذا كان محرك البرمجة المحلي مرتبطاً بمجلد على الكمبيوتر (`localAgentOrigin() && agentDirectory()`). ولذلك كان يظهر في بعض المشاريع ويختفي بمجرد ربط مجلد محلي.

## ما تغيّر؟
- يبقى زر «ملفات المشروع» ظاهراً **داخل قسم «الشغل»** سواء كان المجلد المحلي مربوطاً أم لا.
- يبقى زر «ربط مجلد الجهاز» مستقلاً عنه، ولا يستبدله.
- عند تشغيل المحرك على مجلد مباشر، توضّح نافذة الملفات أن محتوياتها هي ملفات المشروع المستوردة داخل سوالف؛ أما ملفات مجلد الكمبيوتر فيقرأها محرك البرمجة مباشرة.
- لم تتغير إعدادات Claude Code أو Docker أو OpenRouter أو صلاحيات v43 أو تخطيط v44.
- تحديث ذاكرة الخدمة إلى `shell-v46` وتغيير إصدار `js/app.js` في HTML حتى لا يظل المتصفح على الكود القديم.

## التركيب (فوق v45)
1. أغلق برنامج/خدمة سوالف المحلية، وخذ نسخة احتياطية من مجلد المشروع.
2. افتح ملف ZIP وانسخ محتوياته إلى مجلد سوالف **الرئيسي** الذي فيه `package.json`، مع الاحتفاظ ببنية المجلدات.
3. وافق على استبدال الملفات المتطابقة: `js/app.js` و`index.html` و`sw.js`. ملفات `tests/` اختيارية إذا كنت لا تجري اختبارات.
4. شغّل `Start-Sowalif.cmd`، ثم افتح `http://127.0.0.1:4781/`.
5. اضغط `Ctrl + Shift + R` لتحديث الصفحة.
6. افتح قسم «الشغل». اربط مجلد الكمبيوتر كما اعتدت؛ يجب أن يبقى زر «ملفات المشروع» ظاهراً بجوار «ربط مجلد الجهاز».

> ملاحظة: إذا كنت تشغّل `Sowalif.exe`، فالتغييرات على ملفات المصدر لا تظهر في EXE القديم إلا بعد إعادة بناء التطبيق (`npm run desktop:build -- --zip`) وتشغيل النسخة الجديدة. أما تشغيل Start-Sowalif.cmd من المشروع المعدّل فيظهرها مباشرة.

**لا تحتاج إلى إعادة إدخال مفتاح OpenRouter أو إعادة تجهيز Docker لهذا الإصلاح.**

## الفرق بين الملفات
زر «ملفات المشروع» يفتح الملفات المستوردة إلى محادثة/مشروع سوالف. إذا كنت قد ربطت مجلداً محلياً مباشرة مع Claude Code، فلا يعني فتح هذه النافذة أنها ستسرد جميع ملفات القرص. للوصول إلى الملفات الفعلية اطلب من المحرك قراءتها، أو استخدم خيارات إدارة الملفات.

## اختبار آلي
من مجلد المشروع:

```powershell
node --test tests/project-files-visibility.test.mjs tests/coding-connection-regression.test.mjs tests/history-layout.test.mjs
```

النتيجة المتوقعة: 9 اختبارات ناجحة. جرى اختبار منطق إظهار الزر في أوضاع مجلد محلي مربوط، ومشروع غير مربوط، وربط مجلد المتصفح؛ لم يُختبر EXE على جهاز المستخدم.
